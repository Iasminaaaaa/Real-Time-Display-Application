## Install

```
Clone the repository:

git clone https://github.com/Iasminaaaaa/Real-Time-Display-Application.git

Open the project folder in Visual Studio Code.

Right-click on index.html and choose "Open with Live Server"
(Requires the Live Server extension)
```

## Usage

```sh
Simply open the application in your browser to see the current time displayed in hours, minutes, and seconds.The clock updates live every second.
```
